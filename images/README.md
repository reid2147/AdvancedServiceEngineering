# images フォルダ

ここに写真を入れると、ページに自動で表示されます。
**ファイル名は下記のとおりにしてください**(小文字・拡張子 .jpg)。

| ファイル名        | 使われる場所                          |
|-------------------|---------------------------------------|
| `hakodate.jpg`    | 函館のカード + カルーセル1枚目        |
| `churaumi.jpg`    | 美ら海水族館のカード + カルーセル2枚目 |
| `kyoto.jpg`       | 京都のカード                          |
| `namba.jpg`       | なんばのカード + カルーセル3枚目      |

- ファイルがまだ無い間は、自動でグレーの仮画像が表示されます(壊れません)。
- 写真を置いたら、リロードするだけで反映されます。
- 横長(例:640×400 くらい)の写真がきれいに収まります。
