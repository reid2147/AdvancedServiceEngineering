### まだ写真が無い場所(仮画像が表示中)
以下の名前で写真を置けば自動で反映されます。

| ファイル名        | 使われる場所 |
|-------------------|--------------|
| `hakodate.jpg`    | 函館のカード |
| `kyoto.jpg`       | 京都のカード |
| `namba.jpg`       | なんばのカード |

- ファイルがまだ無い間は、自動でグレーの仮画像が表示されます(壊れません)。
- 写真を置いたら、リロードするだけで反映されます。
- ファイル名を変えたい場合は `../script.js` の `spots` 配列内のパスを合わせてください。
